# MCP server 部署检查清单

## 协议接入
- [ ] transport 确定：stdio（Local）或 StreamableHTTP（Remote），不混用
- [ ] tools/list 里每个工具都有 description（宿主据此选工具，缺失=工具不被调用）
- [ ] 工具命名用动词短语，与系统术语一致

## 安全
- [ ] 工具默认只读；写操作必须有确认参数
- [ ] 出网请求走 allowlist（参考骨架 fetch_json 的实现）
- [ ] 不把生产地址/账密写进代码或 README（用环境变量）
- [ ] AI 宿主的输出当作不可信输入处理（提示注入防御）

## 缓存（如接 Redis 等）
- [ ] key 命名有前缀（如 `sys2mcp:`），避免撞业务键
- [ ] TTL 明确，默认值写进文档
- [ ] 失效策略：改数据时谁负责清缓存，写清楚

## 验收
- [ ] 每个工具至少 1 条 e2e 断言（调用→返回结构→关键字段）
- [ ] 断言结果留痕（验收报告），不靠口头
- [ ] 变更过 change-gate 三道门

## 上线后
- [ ] 版本号与 Release tag 对齐
- [ ] README 的安装命令在干净环境实测过一次
