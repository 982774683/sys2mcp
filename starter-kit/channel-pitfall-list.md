# 个人开发者 AI 变现渠道避坑清单（演示包附件 · 2026-11）

> 来源：2026-11-15 全渠道调研（海外付费市场 / Skill 市场 / 国内平台 / 定制接单），证据分级：✅ 实测 ｜ 🟡 平台自述需复访。

## 一、先卡收款，再看分成

| 坑 | 事实 | 结论 |
| --- | --- | --- |
| Stripe 不收大陆主体 | 个人、公司均不受理 | 海外平台写着「Stripe Connect 结算」的，分成先当收不到 |
| 海外 MoR 兜底 | Creem：自然人身份证入驻、提现支付宝（单笔上限 ¥5 万）；Paddle：个人可入驻、Payoneer 出款 | 需要收美元时从这两家走 |
| Gumroad / Lemon Squeezy | 大陆只能 PayPal 出款，费率高 | 不推荐 |
| USDC / x402 稳定币 | 个人无法合规落地 | 否决 |

## 二、国内大厂平台：企业资质通道

| 平台 | 门槛 | 结论 |
| --- | --- | --- |
| 阿里百炼 MCP 广场 | 执照满 1 年 + 注册资本 ≥100 万 + 保证金 3 万；必须托管阿里云网关；控制台无自助发布入口（2026-11-15 实测） | ✗ 注册公司后复访 |

| 腾讯元器 | 微信支付 MCP 内置，走公众号/企微分发 | 仅做微信私域才考虑 |

## 三、收录站：免费，但口径要实测

- **mcp.so**：免费提交走审核（仓库 URL 自动抓取）；$39 是可选付费加速（免审核+徽章+featured），不是强制上架费。
- **Smithery / Glama**：免费，GitHub 账号即可提交。
- 纪律：任何「收不收费」的搜索结果都可能过时，提交前到官方页面亲眼确认（5 分钟）。

## 四、Skill 市场：卖文件不值钱

- 卖 SKILL.md 文件转化差；卖「编码了专业判断的服务」（审计、合规检查、行业报告）才是溢价区。
- 「一下午能写出来」的通用能力（代码审查、commit 生成器）没人付钱。
- Anthropic 官方 Skills Marketplace 付费档口径多源冲突，入场前复访官方文档。

## 五、定价锚点（定制接单）

| 档位 | 海外 agency 报价 | 国内个人参考 |
| --- | --- | --- |
| 单系统 MVP（1-3 工具） | $4k-12k | ¥99-999 引流档 + 议价 |
| 生产级（5-15 工具+OAuth+托管） | $18k-55k | ¥5k-15k 企业档 |
| 多系统/合规 | $60k-250k | 面议 |

低价 SKU 只做引流，真实预算用企业定制档承接。

## 六、执行纪律（少踩 90% 的坑）

1. **证据先行**：无准入证据的渠道不排期。
2. **收款先行**：没确认「钱能回到身份证/支付宝」之前，不做产品改造投入。
3. **payout 硬闸门**：海外平台未在后台亲眼确认 payout 支持支付宝/Payoneer/PayPal 之前，不上付费档。
4. **个人身份**：不冒充公司主体，个人开发者反而更可信。
5. 外汇红线：个人每年 $5 万结汇额度，验证期够用。
