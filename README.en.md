## The problem

- Wiring business systems into AI hosts (CodeBuddy / Claude Code / Cursor) means manual integration, caching and verification on every change.
- No change gate: risky operations (production access, data cleanup) rely on discipline alone.
- Verification leaves no trace: no assertions, no report.
